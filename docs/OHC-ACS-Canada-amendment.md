### OHC-01 Task D — Canadian Jurisdictional Framework

**Objective.** Determine whether Canadian federal or provincial OH&S governs the crane, and name the consensus spine (CSA B167) and authorization model.

**References:** CSA B167 (by name) · Canada Labour Code Part II / COHSR · Ontario OHSA Reg. 851 / 213 · WorkSafeBC Part 14 · Alberta OHS Code Part 6 · Quebec LSST / CNESST

#### Knowledge

- `OHC.01.D.K1` CSA B167 as the Canadian consensus spine for overhead travelling cranes (design, inspection, testing, maintenance, safe operation), cited beside ASME B30 volumes by configuration
- `OHC.01.D.K2` Federally regulated workplaces: Canada Labour Code Part II / COHSR path
- `OHC.01.D.K3` Provincial overlays — Ontario Reg. 851 / 213, WorkSafeBC Part 14, Alberta OHS Code Part 6, Quebec CNESST / LSST
- `OHC.01.D.K4` Canadian authorization model: competent / qualified worker under the applicable Act + **employer written authorization** (Designation Gate analogue — not NCCCO)
- `OHC.01.D.K5` Training establishes standard of care; does not replace employer due diligence under Canadian OH&S statutes

#### Risk Management

- `OHC.01.D.R1` Applying US OSHA/NCCCO routing to a Canadian workplace and treating it as compliance
- `OHC.01.D.R2` Ignoring provincial differences (especially Quebec language-of-work and documentation expectations)
- `OHC.01.D.R3` Treating CSA B167 as optional when the employer’s programme or AHJ expects it as the operating standard

#### Skills

- `OHC.01.D.S1` Select the correct Canada branch (federal vs named province) for a given site
- `OHC.01.D.S2` State that CSA B167 is the consensus spine and where ASME still informs configuration practice
- `OHC.01.D.S3` Produce or request the employer written authorization / designation for the assigned crane

**Census delta (OHC-01):** +5 K · +3 R · +3 S = **+11 elements** (module 37 → 48 if stacked on the Part 1910 net-new K pair; track 400 → 411). Gate items for D are authored in OHC-01; PES gains three Canada performance lines on the M01 sheet addendum.
