# OHC — Canada Jurisdiction Pack

**Course:** OCO301C · Overhead Crane Operator Track  
**Purpose:** Give a Canadian safety director a defensible mapping from the shared OHC ACS to CSA B167 and provincial / federal OH&S — without forking twelve modules into a separate “Canada course.”

---

## Standing rule (unchanged)

Training establishes the operator’s **standard of care**. It does **not** confer qualification. The **controlling entity** (employer) issues written authorization / designation. Same Gate Master doctrine as the US track.

---

## Consensus spine

| Layer | Instrument | Role in OHC |
|---|---|---|
| Shared physics / ops | OHC-02 … OHC-11 ACS elements | Same hazards on both sides of the border |
| Canadian consensus | **CSA B167** — Overhead travelling cranes — Design, inspection, testing, maintenance, and safe operation | Cite beside ASME B30.2 / B30.17 for configuration, inspection, and operating discipline |
| US consensus (still taught) | ASME B30.2 / B30.17 / B30.16 / B30.9 / B30.20 / P30.1 | Name-attributed; edition follows jurisdiction |

**Product claim to use:** *CSA B167-aligned competency programme with employer designation* — not “CSA certified” unless a formal scheme is separately contracted.

## Element crosswalk (minimum)

| OHC theme | US cite (existing) | Canada cite (add) |
|---|---|---|
| Equipment class / configuration | §1926.1438(b)(1), ASME B30.2/17 | CSA B167 scope + classification |
| Who may operate | §1910.179(b)(8) Designation Gate | Employer duty to ensure competence + written authorization |
| Inspection regime | §1910.179(j)/(m); §1926.1412/1413 | CSA B167 inspection / testing clauses + provincial rules |
| Load handling / signals | §1910.179(n); Subpart CC signals | CSA B167 operating rules + site signal plan |
| Records / requalification | OHC-12 | Retain training, PES, designation; re-evaluate after incident / equipment change / lapse |
